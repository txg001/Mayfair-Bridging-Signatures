To install a signature: click “Copy signature”, then paste directly into your email client's signature editor (Gmail: Settings → See all settings → Signature · Outlook: Settings → Mail → Compose and reply → Email signature · Apple Mail: Settings → Signatures). If the button doesn't work in your browser, open the individual HTML file for that person, select all, and copy.
